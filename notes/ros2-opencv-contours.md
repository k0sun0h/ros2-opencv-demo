# 윤곽 검출 · 특징 추출 (10/15)

## 개념
- 윤곽(contour) = 마스크의 흰 덩어리 **테두리**. 점들의 목록
- 10/14 의 마스크는 흰 점들의 모음일 뿐 → findContours 가 흰 덩어리를 **하나씩 분리**해 윤곽을 따준다
- 특징(feature) = 면적·중심·둘레·원형도·외접박스 → "물체가 **어디에, 얼마나 크게, 어떤 모양**인가"
- 로봇이 물체를 따라가려면 필요한 값이 바로 이 **중심 좌표**

## 윤곽 검출
| 인자 | 뜻 |
| --- | --- |
| cv2.RETR_EXTERNAL | 바깥 윤곽만 (구멍 속은 무시) — 물체 개수 셀 때 기본 |
| cv2.CHAIN_APPROX_SIMPLE | 직선 구간은 양 끝점만 저장 (점 개수 절약) |

```
contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
print("찾은 윤곽 개수:", len(contours))
```

## 특징 계산
| 함수 | 뜻 |
| --- | --- |
| cv2.contourArea(c) | 면적 (덩어리 넓이) |
| cv2.arcLength(c, True) | 둘레 (True = 닫힌 도형) |
| cv2.moments(c) | 무게중심 계산용 (m10/m00, m01/m00) |
| cv2.boundingRect(c) | 외접 사각형 (x, y, w, h) |
| 원형도 = 4π·면적 ÷ 둘레² | 1에 가까우면 원, 낮으면 각진 모양 |

```
area = cv2.contourArea(c)
peri = cv2.arcLength(c, True)
M = cv2.moments(c)
if M['m00'] == 0: continue
cx, cy = int(M['m10']/M['m00']), int(M['m01']/M['m00'])
x, y, w, h = cv2.boundingRect(c)
```

- **면적 필터 필수** (`if area < 100: continue`) → 마스크에 남은 작은 티끌도 다 윤곽으로 잡힌다
- **m00 == 0 가드 필수** → 0으로 나누기 에러 방지

## 실험 결과 (10/15 실제 관찰값)
- 실행 : python3 contour_demo.py → "찾은 윤곽 개수: 4" (필터 통과 3개 출력)
- 도형 : 큰 원(150,120,r70) / 사각형(330,60)~(500,190) / 작은 원(140,300,r35) / 작은 점(400,320,r6)

| 도형 | 관측 면적 | 이론 면적 | 관측 둘레 | 이론 둘레 | 중심 | 원형도 |
| --- | --- | --- | --- | --- | --- | --- |
| 큰 원 | 15172 | π·70² = 15394 | 458 | 440 | (150,120) | 0.91 |
| 작은 원 | 3750 | π·35² = 3848 | 227 | 220 | (140,300) | 0.91 |
| 사각형 | 22100 | 170×130 = 22100 | 600 | 600 | (415,125) | 0.77 |
| 작은 점 | 버려짐 | π·6² ≈ 113 | - | - | - | - |

- 중심은 **그린 좌표와 완전히 일치** : 큰 원 (150,120), 작은 원 (140,300), 사각형 ((330+500)/2, (60+190)/2) = (415,125)
- 사각형 면적·둘레는 **이론값과 정확히 일치** (22100 / 600)
- 원의 면적은 이론값의 약 98.5%, 둘레는 조금 크게 나옴 → 화소(pixel) 격자라 원이 계단 모양이기 때문
- 원형도 : 원 0.91 (완전한 원 = 1.0) / 사각형 0.77 (170×130 직사각형 이론값 0.771, 정사각형 최대 0.785)
- "찾은 윤곽 개수 4" vs "출력 3" → 작은 점이 **면적 필터(area<100)로 걸러진 것** (찾은 개수 ≠ 쓸 개수)

## 자주 나는 함정
| 증상 | 원인 / 해결 |
| --- | --- |
| 찾은 윤곽 개수와 출력 개수가 다름 | 면적 필터로 작은 티끌을 버렸기 때문 (정상) |
| 작은 노이즈까지 물체로 잡힘 | 면적 필터(area<100) 또는 MORPH_OPEN 으로 제거 |
| 0으로 나누기 에러 (ZeroDivisionError) | M['m00'] 이 0 → `if M['m00'] == 0: continue` |
| 원형도가 1이 안 나옴 | 화소 격자라 원이 계단 모양 → 0.9 근처가 정상 |
| findContours 반환값이 2개 | OpenCV 4.x 는 (contours, hierarchy) 2개 반환 (3.x 는 3개) |

## 배운 점
- 마스크는 "흰 점 모음", 윤곽은 "**덩어리별 테두리**" — findContours 가 그 사이를 이어준다
- 물체의 정체성은 **중심 좌표**로 요약된다 → 로봇이 물체를 따라갈 때 쓰는 값
- **면적과 원형도**로 물체를 걸러낼 수 있다 (작은 노이즈 버리기, 원/각진 모양 구분)
- 숫자가 이론값과 맞는지 **검산**하면 코드가 제대로 동작하는지 알 수 있다
- 찾은 개수 ≠ 쓸 개수 (필터가 중간에 걸러낸다)
