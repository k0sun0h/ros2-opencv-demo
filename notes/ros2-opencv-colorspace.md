# 색공간 변환 · 이진화 · 필터링 (10/14)

## 개념
- 로봇이 "색으로 물체를 찾으려면" 색을 숫자로 구분할 수 있어야 한다
- 색공간 = 색을 숫자로 표현하는 방법
  - BGR : 파랑·초록·빨강의 밝기 3개. 화면 표시·저장용
  - HSV : 색상(H)·진하기(S)·밝기(V). 밝기와 색이 분리되어 조명이 변해도 색이 유지됨
- OpenCV 의 H 는 0 ~ 180 (일반 HSV 는 0 ~ 360 → 절반으로 압축). S·V 는 0 ~ 255
- inRange = "이 범위 색만 남겨라" → 마스크 생성 (흰색=해당 색, 검정=아님)
- 이진화 = 회색조로 바꾼 뒤 기준값보다 밝으면 흰색, 어두우면 검정 (색 정보가 사라지고 밝기만 남음)
- 필터링 = 노이즈 제거. 특히 모폴로지 open(작은 흰 점 제거) / close(작은 검은 구멍 메움)

## 색공간 변환 (BGR → HSV)
| 색 | H 범위 (OpenCV) |
| --- | --- |
| 빨강 | 0 ~ 10, 170 ~ 180 |
| 주황 | 10 ~ 25 |
| 노랑 | 25 ~ 35 |
| 초록 | 40 ~ 80 |
| 파랑 | 90 ~ 130 |
| 보라 | 130 ~ 160 |

```
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
lower = np.array([90, 100, 100])
upper = np.array([130, 255, 255])
mask = cv2.inRange(hsv, lower, upper)
```

- H 만 좁게 잡고 S·V 는 100~255 → 너무 어둡거나 색이 흐린 픽셀은 제외
- OpenCV 색 순서는 RGB 가 아니라 BGR (10/13 과 같은 함정)

## 이진화
| 방식 | 기준값 | 언제 |
| --- | --- | --- |
| cv2.THRESH_BINARY | 내가 직접 지정 | 조명이 일정할 때 |
| cv2.THRESH_OTSU | 자동으로 찾아줌 | 조명이 매번 다를 때 (실무 기본) |
| cv2.adaptiveThreshold | 픽셀마다 지역별로 | 그늘이 심할 때 |

```
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
ret, bw = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
print("Otsu 자동 기준값:", ret)
```

- Otsu 는 밝기 히스토그램의 봉우리 두 개 사이를 골라 기준값을 자동 결정 → 0 을 넣어도 채워진다

## 필터링
| 함수 | 하는 일 |
| --- | --- |
| cv2.GaussianBlur | 전체를 뿌옇게 (잡음 완화) |
| cv2.medianBlur | 중간값으로 대체 (소금·후추 노이즈에 강함) |
| cv2.bilateralFilter | 경계는 살리고 속만 부드럽게 |
| cv2.morphologyEx | 흰 영역 모양 정리 (open / close) |

```
kernel = np.ones((5, 5), np.uint8)
mask = cv2.morphologyEx(mask, cv2.MORPH_OPEN, kernel)   # 작은 흰 점 제거
```

- MORPH_OPEN = 작은 흰 점 제거 / MORPH_CLOSE = 작은 검은 구멍 메움
- 파이프라인 순서 : imread → BGR2HSV → inRange(마스크) → MORPH_OPEN → BGR2GRAY → OTSU

## 자주 나는 함정
| 증상 | 원인 / 해결 |
| --- | --- |
| mask 가 전부 검정 | 색 범위에 걸리는 픽셀이 없다 (에러 아님) → BGR 순서 확인 후 H 범위 조정 |
| (60,120,200) 을 파랑으로 만들었는데 안 잡힘 | OpenCV 는 BGR 순서 → 실제로는 B=60,G=120,R=200 = 주황. 파랑은 (200,120,60) |
| binary 가 검정 배경 + 흰 글씨 | 원본에서 글씨가 더 밝아서 (정상) → 흰 배경 + 검정 글씨가 되려면 글씨가 더 어두워야 함 |
| 밝기가 같은 다른 색이 구분 안 됨 | 이진화는 색을 못 본다 (밝기만) → 색 구분은 HSV + inRange 로 |

## 배운 점
- 색 찾기 = HSV 문제, 밝기 구분 = 이진화 문제. 둘을 헷갈리면 안 된다
- 이진화의 흑백은 "글씨냐 배경이냐"가 아니라 "밝으냐 어두우냐"로 정해진다
- 회색조로 바꾸면 색 정보는 사라진다 (순수 빨강 76 = 어두운 초록 76 처럼 다른 색이 같은 밝기가 될 수 있음)
- mask 가 전부 검정 = 에러가 아니라 "그 색이 없다"는 정상적인 결과
- 색이 안 잡힐 때 점검 순서 : ① BGR 순서 확인 → ② H 범위를 실험으로 조정
