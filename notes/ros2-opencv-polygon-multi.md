# 다각형 근사 · 다중 물체 검출 (10/15 심화)

## 개념
- approxPolyDP = 윤곽(점 수백 개)을 **꼭짓점 몇 개로 단순화** → "이 도형은 몇 각형인가"를 판정
- epsilon = 허용 오차. 직선에서 얼마나 벗어나면 꼭짓점으로 볼지 정한다
  - 작으면 → 꼭짓점 많음 (원래 모양에 가까움)
  - 크면 → 꼭짓점 적음 (단순화, 너무 키우면 도형이 망가짐)
- 색이 다른 물체 여러 개 = 색 범위를 **여러 개 돌리면서** 각각 findContours → 한 프레임에서 동시 검출
- 같은 색 물체 2개 → 한 색 범위에서 **윤곽 2개**가 나온다 (색은 이름표, 개수는 윤곽이 알려줌)
- 프레임 간 추적 = 프레임마다 중심 좌표를 뽑아 이어 붙이면 그게 물체의 궤적

## 다각형 근사 (approxPolyDP)
| 인자 | 뜻 |
| --- | --- |
| cnt | 윤곽 (점 목록) |
| epsilon | 허용 오차 (보통 **0.02 × 둘레**) |
| True | 닫힌 도형으로 취급 |

```
peri = cv2.arcLength(c, True)
approx = cv2.approxPolyDP(c, 0.02 * peri, True)
print(len(approx))          # 꼭짓점 개수
```

## 도형 분류 규칙 (실무)
| 조건 | 판정 |
| --- | --- |
| len(approx) == 3 | 삼각형 |
| len(approx) == 4 | 사각형 |
| 원형도 ≥ 0.85 | 원 |
| 그 외 | N각형 |

- **원 판정을 꼭짓점 개수로 하면 안 된다** : 화소 때문에 원도 꼭짓점이 8개쯤 나온다 → **원형도**로 판단

- 정사각형·작은 사각형의 면적은 **이론값과 정확히 일치** (14400 / 3600)

### 2) epsilon 민감도 (파란 원 하나, 둘레 392)

| eps | 꼭짓점 개수 | 결과 |
| --- | --- | --- |
| 0.005 × 둘레 (2.0) | 16개 | 거의 원래 윤곽 |
| 0.010 × 둘레 (3.9) | 16개 | 그대로 |
| **0.020 × 둘레 (7.8)** | **8개** | 실용 구간 (원으로 인식) |
| 0.050 × 둘레 (19.6) | 4개 | **도형이 망가짐** (원인데 사각형) |
| 0.100 × 둘레 (39.2) | 4개 | 더 망가짐 |

- **epsilon 을 키우면 단순해지지만, 너무 키우면 원이 4각형이 된다** → 0.02 × 둘레가 안전한 기본값

| 같은 색 물체가 하나로 합쳐짐 | 두 물체가 붙어 있으면 윤곽이 1개 → MORPH_OPEN 또는 물체 분리 |
| 색이 안 잡힘 | H 범위 조정 (10/14 함정과 동일). 빨강은 0~10 + 170~180 두 구간 |
| putText 라벨이 `????` 로 깨짐 | **cv2.putText 는 ASCII(영문) 폰트만 지원** → 한글 불가. 해결: 라벨을 영문으로 쓰거나, **PIL(ImageDraw)로 그린다** (아래) |
| `OSError: cannot open resource` (폰트 줄) | 그 경로에 폰트 파일이 **없음** → `sudo apt install -y fonts-nanum` 후 **경로를 자동 탐색**하게 고친다 (아래) 

## 화면에 한글 쓰기 (PIL)
- cv2.putText 는 Hershey 폰트만 있어서 **한글이 안 나온다** (`????` 로 깨짐)
- PIL(ImageDraw) 로 그리면 한글이 정상 출력된다

```
from PIL import Image, ImageDraw, ImageFont

pil = Image.fromarray(cv2.cvtColor(out, cv2.COLOR_BGR2RGB))
draw = ImageDraw.Draw(pil)
font = ImageFont.truetype("/usr/share/fonts/truetype/nanum/NanumGothic.ttf", 16)
draw.text((cx - 55, cy - 30), f"{cname} {shape}", fill=(0, 0, 0), font=font)
out = cv2.cvtColor(np.array(pil), cv2.COLOR_RGB2BGR)   # 다시 OpenCV 로
```

- 폰트가 없으면 `fc-list :lang=ko` 로 나눔/은글꼴 경로를 찾아 쓴다
- 대안: 라벨을 영문(`RED TRIANGLE`)으로 쓰면 cv2.putText 로도 가능

## 폰트 함정 — 경로가 다르면 OSError

- 폰트 경로를 **하드코딩하면** 그 파일이 없을 때 `OSError: cannot open resource` 로 죽는다
- WSL 에 나눔폰트가 없으면 설치 : `sudo apt install -y fonts-nanum`
- 경로가 환경마다 다르므로 **자동 탐색**으로 쓴다 (없어도 에러 없이 기본 폰트로)

```
import glob
cands = (glob.glob("/usr/share/fonts/**/NanumGothic*.ttf", recursive=True)
         + glob.glob("/usr/share/fonts/**/UnDotum*.ttf", recursive=True))
font = ImageFont.truetype(cands[0], 16) if cands else ImageFont.load_default()
print("폰트:", cands[0] if cands else "없음")
```

- 실제 결과 : `폰트: /usr/share/fonts/truetype/nanum/NanumGothicCoding.ttf` → 한글 라벨 정상 출력

## waitKey — 왜 다음 스크립트가 안 돌아가나
| 호출 | 뜻 | 결과 |
| --- | --- | --- |
| `cv2.waitKey(0)` | **무한 대기** (키 입력까지) | 창을 닫을 때까지 **다음 명령이 실행되지 않음** |
| `cv2.waitKey(50)` | 50ms 만 기다림 | 저절로 넘어감 (`track_ball.py` 의 영상 루프) |
| `cv2.waitKey(3000)` | 3초 | 3초 뒤 자동 종료 |

- 첫 스크립트가 안 끝난 게 아니라 **키를 기다리는 중** → **창에서 아무 키나 누르면** 다음 명령이 돈다
- `python3 a.py` 와 `python3 b.py` 를 붙여서 실행하면, a 가 `waitKey(0)` 에서 멈춰 b 가 안 도는 것처럼 보인다 (10/13 부터 배운 "0 = 무한 대기")

## 배운 점
- 윤곽은 점 수백 개지만 **approxPolyDP 로 몇 개의 꼭짓점으로 요약**하면 도형 이름을 붙일 수 있다
- **cv2.putText 는 한글을 못 쓴다** → 화면에 한글을 쓰려면 **PIL** 을 쓴다
- 폰트 경로는 **자동 탐색**으로 (하드코딩하면 `OSError: cannot open resource`)
- `cv2.waitKey(0)` 은 무한 대기 → 다음 명령이 안 도는 것처럼 보인다
- epsilon 은 "얼마나 단순화할지" 손잡이. **작으면 자세히, 크면 단순하게(과하면 망가짐)**
- 색은 **이름표**, 윤곽은 **개수** → 색 범위 여러 개를 돌리면 다중 물체를 동시에 잡는다
- 물체 추적의 실체는 **프레임마다 중심 좌표를 뽑아 잇는 것** (복잡한 게 아니다)
- 검산 습관 : 면적은 이론값(πr², 가로×세로)과, 중심은 그린 좌표와 비교 → 오차 0 확인
